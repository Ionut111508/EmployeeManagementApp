Employee Management App

A simple Employee Management System built with C# and SQL, designed to demonstrate backend development, database integration, and CRUD operations for employee and project management.

🧰 Technologies

Backend: C# (.NET / .NET Core)

Database: SQL Server (with .sql scripts)

IDE: Visual Studio (.sln solution)

Version Control: Git & GitHub

⚙️ Features

Create, Read, Update, Delete employees

Manage projects and employee assignments

SQL database integration via scripts

🚀 Setup

Clone Repository:

git clone https://github.com/Ionut111508/EmployeeManagementApp.git


Database: Execute the provided .sql scripts in SQL Server

Backend: Open ManagementulProiectelor.sln in Visual Studio, build and run

API: Application exposes REST endpoints for managing employees and projects

📌 Skills Demonstrated

Backend development with C# and .NET

Database design and SQL scripting

CRUD operations and REST API design

Visual Studio and solution structuring
